# Roadmap

What may come next in ace2k. No dates are promised. What does not work today is in
[Known limitations](limitations.md).

- Several ACE 2 Pro units on one printer, each on its own USB connection (a USB hub works for
  that). Nothing is decided yet. If another project can already drive several units, such as
  [AFC-Klipper](https://github.com/AFCProject/AFC-Klipper-Add-On), ace2k will not repeat that work.
  Chaining units on one port is not planned
  ([decision 0002](decisions/0002-one-unit-per-serial-port.md)). Today exactly one unit is
  supported and tested.
- A remaining-filament estimate per spool.
- Rotating the spool while drying (rotisserie).
- Writing tags.
- Variable fan speed (today the fans are on or off only).
- An automatic baseline for the insert sensor.
- A fixed address per unit.
- A per-lane odometer.
