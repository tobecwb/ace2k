# Credits

ace2k stands on published work. Each file that derives from a source names it in its header
comment; this page lists them all.

- **[hakimio](https://github.com/hakimio)** — the ACE 2 Pro protocol, its published schema, the interactive shell and the OTA
  updater the flashing guide relies on.
  <https://github.com/hakimio>,
  shell and schema <https://gist.github.com/hakimio/551915aa02b7e248721bed672ad46e0b>,
  updater <https://gist.github.com/hakimio/39c71fa7174e699c6470b7c79323b189>.
- **[Simon-CR](https://github.com/Simon-CR)** — `ace2-pro-firmware-research`: the reader protocol, the spool-rotation concept, UID
  passthrough and the motion-yield rule. <https://github.com/Simon-CR/ace2-pro-firmware-research>
- **DnG-Crafts** — the Anycubic tag layout (<https://github.com/DnG-Crafts/ACE-RFID>) and the
  Creality tag's key derivation and layout (<https://github.com/DnG-Crafts/K2-RFID>).
- **OpenRFID** (suchmememanyskill) — the Snapmaker and Elegoo tag layouts and the Snapmaker public
  keys; an RFID project in its own right. <https://github.com/suchmememanyskill/OpenRFID>
- **Snapmaker `u1-klipper`** — the open reader driver. <https://github.com/Snapmaker/u1-klipper>
- **Bambu-Research-Group / RFID-Tag-Guide** — Bambu key derivation and layout.
  <https://github.com/Bambu-Research-Group/RFID-Tag-Guide>
- **Elegoo** — the official tag guide. <https://github.com/elegooofficial/ELEGOO-RFID-Tag-Guide>
- **OpenSpool** — the NDEF spool format. <https://github.com/spuder/OpenSpool>
- **Klipper** — the MCU framework this firmware is built on. <https://github.com/Klipper3d/klipper>

A tag *layout* or a *key* is a fact and needs a credit; *code* ported from a project needs a
GPL-3.0-compatible licence and keeps its original header.
